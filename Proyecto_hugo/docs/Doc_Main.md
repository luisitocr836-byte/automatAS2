Propósito
- Programa de consola con un menú para operar un `ArbolBB` (crear, recorrer, eliminar, buscar).

Funciones / flujo
- `menu(op)`: muestra el menú y solicita opción al usuario.
- El `main` crea un objeto `ArbolBB`, llama a `crea_cab()` y ejecuta el bucle del menú.
- Opciones disponibles: insertar, preorden, inorden, postorden, eliminación, buscar, salir.

Uso
- Ejecutar: `python Main.py` y seguir las indicaciones en consola.

Notas
- La inserción (`insertar`) solicita al usuario un valor numérico.
- Los recorridos usan los métodos `preorden`, `inorden`, `postorden` de `ArbolBB`.
- Código simple, pensado para interacción manual en consola.
