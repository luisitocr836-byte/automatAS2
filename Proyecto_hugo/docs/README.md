Documentación breve para los módulos usados por el "árbol provisional".

Archivos:
- Doc_arbolProvisional.md — GUI para BST y árbol de expresiones.
- Doc_albol.md — Construcción de árbol de expresiones (infija→postfija).
- Doc_prueba_arbol.md — Script simple para probar la conversión y recorridos.
- Doc_Main.md — Menú interactivo para operaciones sobre `ArbolBB`.
- Doc_ArbolBB.md — Clase `ArbolBB`: nodo, inserción, recorridos, eliminación, búsqueda.
- Doc_Pila.md — Implementación sencilla de pila usada para construir árboles.

Cada archivo contiene explicaciones muy simples y ejemplos de uso.
