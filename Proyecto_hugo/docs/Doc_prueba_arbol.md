Propósito
- Script simple para leer una expresión desde la entrada estándar, construir un árbol de expresiones y mostrar los recorridos.

Qué hace
- Pide al usuario la expresión infija.
- Construye el árbol con `Arbol_expresiones`.
- Imprime Preorden, Inorden y Postorden.

Uso
- Ejecutar: `python prueba_arbol.py` y escribir la expresión cuando se solicite.

Nota
- El script contiene comentarios informales/privados que no afectan la ejecución; puedes eliminar esos comentarios si quieres un archivo más limpio.
